# ProjetPsinCss
Projet CSS, avril 2026, pour apprendre les base de l'html
Ce projet a été réalisé dans le cadre de ma formation PSIN afin d’apprendre à utiliser le CSS et à améliorer la mise en forme d’un site web à travers la création de styles personnalisés.

L’objectif était d’ajouter une mise en page simple en utilisant un fichier CSS relié au projet HTML existant.

Le projet contient un dossier CSS permettant de gérer l’apparence du site, notamment avec l’ajout d’une image de fond fixe afin qu’elle reste immobile lors du défilement de la page.

Ce travail m’a permis de découvrir le lien entre les fichiers HTML et CSS, ainsi que les bases de la personnalisation visuelle d’un site web.
